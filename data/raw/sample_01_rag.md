# Введение в RAG (Retrieval-Augmented Generation)

RAG (Retrieval-Augmented Generation) — это подход в разработке систем искусственного интеллекта, который объединяет два компонента: **извлечение информации** (retrieval) и **генерацию текста** (generation). 

## Как работает RAG

1. **Извлечение информации**: Система находит релевантные документы или фрагменты информации из большой базы знаний по запросу пользователя.
2. **Генерация**: LLM использует найденную информацию для формирования точного и обоснованного ответа.

## Преимущества RAG

- **Актуальность информации**: Ответы основаны на актуальных данных, а не только на знаниях, заложенных в модель при обучении.
- **Обоснованность**: Система может указать источники информации, что делает ответы более прозрачными.
- **Масштабируемость**: База знаний может обновляться без переобучения модели.
- **Уменьшение галлюцинаций**: За счёт ограничения контекстом, модель реже придумывает информацию.

## Когда использовать RAG

RAG особенно полезен в таких сценариях:

- Вопросы по внутренней документации компании
- Техническая поддержка
- Анализ юридических документов
- Научные исследования с большими корпусами текстов

## Компоненты RAG системы

### Векторные базы данных

Для эффективного поиска по большому объёму текста используются **векторные базы данных** (Vector DB). Они хранят не сами тексты, а их **эмбеддинги** — числовые векторы, которые отражают смысл текста.

Популярные векторные базы данных:
- Qdrant
- Pinecone
- Weaviate
- Milvus

### Эмбеддинг-модели

Для преобразования текста в векторы используются специальные модели:
- OpenAI embeddings
- Hugging Face embeddings (например, BAAI/bge-m3)
- Sentence Transformers

Эмбеддинги позволяют находить семантически похожие тексты даже при разных формулировках.

## Chunking (чанкинг)

Документы обычно слишком большие для обработки целиком, поэтому их разбивают на фрагменты — **чанки**. Оптимальные параметры:
- Размер чанка: 1200 символов
- Перекрытие: 200 символов

Перекрытие важно, чтобы сохранить контекст между соседними чанками.

## Будущее RAG

Технологии RAG активно развиваются:
- **Гибридный поиск**: комбинация семантического и полнотекстового поиска
- **Reranking**: переупорядочивание результатов для улучшения релевантности
- **Мульти-модальность**: работа не только с текстом, но и с изображениями, аудио, видео
- **Агентные системы**: автономные решения, которые сами решают, когда использовать RAG
